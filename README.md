# Os Frascos das Emoções

Atividades sobre a história «O Monstro das Cores», de Anna Llenas, para o pré-escolar e o 1.º ciclo.

- **6 atividades digitais interativas**: arrumar emoções, check-in emocional, o meu frasco, detetive das emoções, caixa de calma e desenho.
- **Caderno de fichas para imprimir** (`Caderno_das_Emocoes.pdf`): 12 fichas de escrita e desenho, um diploma e notas para o professor.
